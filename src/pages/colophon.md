This website is still under construction and is always being maintained. I started working on it during the autumn and winter of 2025. I had wanted to create my own website for several years, but I had never really made the time for it.

For a while, I tried building it with Hugo and Jekyll, but I felt more comfortable using Astro, which is what the website is built with now. I also managed to deploy the website on Neocities for a while, but I eventually moved it to Cloudflare.

I considered using GitHub Pages, but I am still slightly embarrassed to show my code. It has improved over time, but my early commit history is a mess and does not always make much sense. (￣▽￣*)ゞ

By the time you read this, it may have become a little more organised and easier to understand. The thing is, before I was just adding things without really thinking much about following an organized workflow. ( ´_ゝ｀)

Perhaps I will make the website open source one day. Before that, I would like to make sure that all its pages work properly with the current design.

Here, I will gradually write about how I created this website, along with small tutorials, useful tips, references, and other notes from the process. Perhaps some of them could be useful to anyone interested in using Astro to build a static website like this one.
